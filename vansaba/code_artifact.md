# ゲーム企画書：『IDOL SURVIVORS（アイドル・サバイバーズ） ～厄介ヲタクから逃げ切れ！～』

## 1. 企画概要

| 項目 | 内容 |
| :--- | :--- |
| **タイトル** | IDOL SURVIVORS（アイドル・サバイバーズ） |
| **ジャンル** | ステージ生存型ローグライトアクション（通称：ヴァンサバ系） |
| **プラットフォーム** | PC (Steam) / スマートフォン (iOS / Android) / Nintendo Switch |
| **プレイ人数** | 1人 |
| **ターゲット層** | アイドルファン、ローグライト好き、カジュアルゲームユーザー |
| **コンセプト** | **「ファンサ（攻撃）で厄介ヲタクを浄化し、伝説の武道館ライブを成功させろ！」** |

### ゲームの目的
プレイヤーは4人の個性豊かなアイドルから1人を選び、ライブ会場や握手会会場に押し寄せる無数の「厄介ヲタク」の波から一定時間（15分〜30分）生き延びることを目指します。
攻撃はすべてオートで行われ、プレイヤーは移動とレベルアップ時の「スキル（ファンサ・アイテム）選択」に集中。無数の厄介ヲタクを「神対応」で浄化し、画面を埋め尽くすほどの派手なパフォーマンスで圧倒する爽快感を提供します。

---

## 2. 世界観・用語設定

舞台は群雄割拠の**「現代アイドル業界」**。
ステージの成功を阻もうと、会場にはマナーを守らない「厄介ヲタク」たちが大量発生！アイドルたちは自身の魅力（攻撃）を振りまき、彼らを「良質なファン（経験値）」へと更生させながら、トップアイドルへの階段を駆け上がります。

*   **HP（体力） ＝ メンタル（精神力）**
    *   厄介ヲタクに接触するとメンタルが削られ、0になると「活動休止（ゲームオーバー）」となります。
*   **経験値ジェム ＝ サイリウム（ペンライト）の欠片**
    *   厄介ヲタクを浄化（撃破）するとドロップ。拾うことで会場のボルテージ（経験値）が上昇します。
*   **宝箱 ＝ 差し入れ（プレゼントBOX）**
    *   中ボス（TO：トップオタ）を倒すとドロップ。豪華な衣装や機材が手に入り、スキルが大幅に強化されます。
*   **回復アイテム ＝ 高級タピオカ / 楽屋のケータリング**
    *   ステージ上の機材（バリケードなど）を壊すと出現し、メンタルを回復します。
*   **通貨 ＝ チェキ売上（チェキ券）**
    *   ステージクリアやプレイ中に獲得。永続的なステータス強化（レッスン）に使用します。

## 3. プレイアブルキャラクター（主人公）

プレイヤーは以下の4人のアイドルから1人を選択してプレイします。

### ① さゆ・すたー
*   **キャッチコピー：** 「銀河系イチの王道キラキラアイドル！」
*   **特徴：** バランス型・初心者向け
*   **初期武器：** **ウインク・ハート**（向いている方向にハート型の光弾を連射）
*   **固有パッシブ：** **『王道の輝き』** - 経験値（サイリウム）の獲得範囲が広く、レベルアップ時の選択肢が1つ増えることがある。

### ② ももる・ましる
*   **キャッチコピー：** 「あなたの心に甘い毒を盛る、病みかわ小悪魔系」
*   **特徴：** テクニカル・範囲攻撃＆状態異常型
*   **初期武器：** **メンヘラ・オーラ**（自身の周囲にピンク色の毒々しいバリアを展開し、近づく敵に継続ダメージ＆鈍足効果）
*   **固有パッシブ：** **『ガチ恋製造機』** - 敵の移動速度を低下させ、デバフ状態の敵に与えるダメージが増加する。

### ③ あう・とにー
*   **キャッチコピー：** 「常識なんてぶっ壊せ！破天荒ロック系パンクアイドル」
*   **特徴：** 高火力・スピード特化型
*   **初期武器：** **デスボイス・シャウト**（全方位に強力な音波を放ち、敵をノックバックさせる）
*   **固有パッシブ：** **『ライブハウス育ち』** - 移動速度と攻撃速度が常に高く、ピンチ（メンタル低下時）になるほど攻撃力が上昇する。

### ④ さーたんまん
*   **キャッチコピー：** 「愛と正義のヒーローアイドル！みんなの笑顔を守るのだ！」
*   **特徴：** 高耐久・物理＆召喚特化型
*   **初期武器：** **さーたんパンチ**（前方広範囲に巨大な拳のエネルギーを叩きつけ、高威力・高ノックバックを与える）
*   **固有パッシブ：** **『鋼のメンタル』** - 最大メンタル（HP）と防御力が高く、ダメージを受けた際に周囲の敵を吹き飛ばす衝撃波を発生させる。

## 4. 武器（ファンサ）＆アイテムシステム

レベルアップ時にランダムで提示される「武器（アクティブスキル）」と「グッズ（パッシブアイテム）」を組み合わせることで、アイドルはどんどん派手になっていきます。

### 武器（ファンサ・パフォーマンス）の例
*   **レス（指差し）：** 画面内のランダムな敵をロックオンし、高威力のレーザービームを放つ。
*   **サインボール投げ：** 画面端で反射するサインボールを投げ、敵の群れを跳ね回りながら攻撃。
*   **爆レス・投げキッス：** 巨大なキスマークを前方に飛ばし、着弾点で爆発を起こす。
*   **神対応・握手会：** 自分の周囲を回転する「握手の手」を召喚し、近づく敵を弾き飛ばす。
*   **MCトーク（長話）：** 一定時間ごとに画面全体の敵の動きを止め、継続ダメージを与える。

### グッズ（パッシブアイテム）の例
*   **厚底ブーツ：** 移動速度アップ。
*   **高性能マイク：** 攻撃範囲アップ。
*   **ファンレターの束：** 経験値獲得量アップ。
*   **マネージャーの護衛：** 被ダメージ軽減。
*   **SNSのバズり：** 発射数（弾数）＋1。

### 武器の進化（覚醒システム）
特定の武器を最大レベルにし、対応するグッズを所持した状態で「差し入れ（宝箱）」を開けると、**『超・神対応（進化武器）』**へと覚醒します！
*   *例：【ウインク・ハート】＋【SNSのバズり】 ＝ **【ビッグバン・ラブ（画面全体を覆う極太ハートレーザー）】***

## 5. 敵キャラクター（厄介ヲタク図鑑）

アイドルのステージを混乱に陥れる、多彩な厄介ヲタクたちが登場します。

*   **最前管理（雑魚・集団）：** 数は多いが体力は低い。最前列を陣取ろうとジリジリと迫ってくる。
*   **オタ芸マン（突撃型）：** サイリウムを激しく振り回しながら、直線的に高速突進してくる。
*   **家虎（イエッタイガー）叫び（遠距離型）：** 離れた位置から「イエッタイガー！」という不協和音の音波（弾幕）を飛ばしてくる。
*   **マサイ族（跳躍型）：** 異常なジャンプ力で障害物を飛び越え、アイドルの近くに急接近してくる。
*   **認知厨（ストーカー型）：** 移動速度が速く、執拗にアイドルの背後を追いかけ回す。
*   **【中ボス】TO（トップオタ）：** 巨大な体躯と圧倒的な財力（体力）を持つ古参ヲタク。倒すと必ず「差し入れ（宝箱）」を落とす。
*   **【ステージボス】炎上系ゴシップ記者：** 制限時間（15分）経過で出現。フラッシュ攻撃やフェイクニュース弾幕を放つ強敵。

## 6. ステージ構成

1.  **ステージ1：秋葉原・地下ライブハウス**
    *   狭い会場に密集するヲタクたち。まずはここからアイドルの伝説が始まる。
2.  **ステージ2：ショッピングモール・リリイベ会場（噴水広場）**
    *   買い物客も混ざるカオスな空間。エスカレーターや噴水が障害物となる。
3.  **ステージ3：真夏の野外アイドルフェス**
    *   広大なステージだが、熱中症（時間経過でスリップダメージエリア発生）などのギミックがある。
4.  **ステージ4：日本武道館（最終決戦）**
    *   360度全方位から数万人のヲタクが押し寄せる、最高難易度のクライマックスステージ。

## 7. マネタイズ・やりこみ要素（想定）

*   **レッスン（永続強化）：** 稼いだ「チェキ売上」を使い、全アイドル共通の基礎ステータスを強化。
*   **衣装チェンジ（スキン）：** 特定の条件（例：「さーたんまんで10,000人のヲタクを浄化する」など）を達成すると、水着衣装やメイド服、私服などのスキンが解放（一部微量のステータスボーナス付き）。
*   **図鑑・実績（トロフィー）：** 浄化したヲタクの種類や、進化させたファンサのコンプリート要素。
